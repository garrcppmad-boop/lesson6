# 自己紹介ページ

プログラミング学習の一環として HTML・CSS で作成した、アニメーション付き自己紹介カードページです。

---

## 概要

| 項目 | 内容 |
|------|------|
| ページ種別 | 自己紹介ページ |
| 表示内容 | 名前・自己PR・趣味リスト・スキルバー |
| 作成日 | 2025年4月24日 |

---

## 使用技術

- **HTML5** — ページ構造（カードレイアウト、リスト、セクション）
- **CSS3** — スタイリング・アニメーション

---

## 主な機能

- グラデーション背景（濃い青 → 水色）
- カードが下からふわっと現れる **フェードインアニメーション**
- 趣味リストの **ホバーエフェクト**（背景色が白 → 濃い青に変化）
- スキルレベルをバーで表示する **スキルバー**（アニメーション付き）
- [Google Fonts](https://fonts.google.com/) の Noto Sans JP を使用したフォント
